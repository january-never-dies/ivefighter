# ivefighter — 1인 격투 데모

`docs/index.html`을 브라우저로 열면 실행됩니다. 게임 서버, 설치, 회원가입이 필요하지 않습니다. 외부 웹 폰트가 로딩되지 않아도 기본 폰트로 실행됩니다.

- 사진 레퍼런스를 반영한 도트 스프라이트 파이터 6명: 장원영, 레이, 가을, 안유진, 리즈, 이서
- CPU 대전만 지원, 쉬움 / 보통 / 어려움
- 60초 라운드, 2선승, KO / 시간 초과 / 무승부, 재대전
- A/D 이동, W 점프, S 앉기 (방향키도 지원)
- Q 캐릭터 고유기, R 초필살기 (게이지 100% 필요)
- 상대 반대 방향 유지: 서서 가드, 뒤 + S: 앉아 가드
- U/I/O: 약/중/강 펀치, J/K/L: 약/중/강 킥
- 앉아 킥: 하단 / 공중 공격: 중단 / 기본 공격 가드 시 피해 없음
- Esc 일시정지, 탭 이탈 자동 일시정지, 선택 가능한 효과음
- 작은 화면에는 터치 버튼 제공. 데스크톱 키보드 사용 권장

## 범위

스트리트 파이터의 6버튼 구성을 참고한 오리지널 프로토타입입니다. 원작의 정확한 프레임, 판정, 콤보 시스템을 복제한 구현은 아닙니다. 고유기와 초필살기는 간편 버튼으로 발동합니다. 커맨드 입력, 잡기, 온라인 및 로컬 2인 대전은 포함하지 않습니다. 연속 타격 표시는 짧은 시간 안의 명중 수이며 확정 콤보 판정이 아닙니다.

렌더링은 생성된 도트 스프라이트와 픽셀 배경을 사용하는 Canvas 방식입니다. 6명 × 8포즈(대기·이동·펀치·킥·하단·가드·피격·점프)를 상태에 연결합니다. 약·중·강은 같은 공격 포즈를 공유하되 발동 시간과 피해량이 다릅니다. 대기는 호흡 움직임, 이동은 두 포즈를 번갈아 표현합니다. 매 프레임을 개별 제작한 풀 애니메이션은 아닙니다.

캐릭터 이미지는 투명 PNG에서 실루엣을 분리해 이웃 프레임이 섞이지 않도록 합니다. 로컬 파일에서도 분리가 가능하도록 아틀라스를 데이터 URL로 포함합니다. 600×300 내부 화면을 최근접 방식으로 확대해 픽셀 경계를 유지합니다.

## 구조

- docs/index.html: 화면 / 조작 안내
- docs/style.css: 반응형 스타일
- docs/game.js: `roster` 캐릭터 수치, `moves` 공격 데이터, `update` 전투, 전투 상태
- docs/skills.js: 여섯 전투 스타일, 기술 타이밍, 사거리, 상성 및 판정
- docs/art.js: `drawModel` 도트 스프라이트 상태 선택, `render` 트레이닝 센터 배경
- docs/assets/fighters.png: 48포즈 투명 아틀라스
- docs/assets/training-center.png: 도트 배경
- docs/assets/sprites-data.js: 로컬 실행용 임베디드 아틀라스
